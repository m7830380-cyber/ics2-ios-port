Internet Cafe Simulator 2 Co-op for Windows
===========================================

You need your own copy of Internet Cafe Simulator 2 from Steam, installed on this PC.

Install
  1. Unzip this folder anywhere.
  2. Double-click "Install ICS2 Co-op.bat".
     It makes a co-op copy next to the Steam game ("Internet Cafe Simulator 2 Co-op").
     The Steam game is not changed and keeps working as before. The copy uses almost no
     extra disk space when it is on the same drive as the game.
  3. Say yes to the firewall question (Windows asks for admin rights once), so friends can join you.
  4. Start "ICS2 Co-op" from the desktop.

Playing together on the same Wi-Fi / LAN
  Host:   load your cafe > pause menu > Co-op > Host this cafe (or main menu > Co-op > Host my cafe).
  Friend: main menu > Co-op > your game appears in the list > tap it.

Playing together over the internet with Radmin VPN (free)
  1. Everyone installs Radmin VPN (radmin-vpn.com) and joins the same Radmin network
     (one of you: Network > Create network; the others: Network > Join network).
  2. Host: Co-op > Host. The Co-op panel shows your "Radmin VPN: 26.x.x.x" address.
  3. Friends: main menu > Co-op. The host usually appears in the list by itself; if not,
     "Join by address" and type the host's 26.x.x.x address.
  If friends cannot connect: on the host PC, allow "Internet Cafe Simulator 2" in Windows Firewall for
  Private AND Public networks (Radmin networks count as Public), or run the installer again and say yes
  to the firewall question.

Everyone must use the same build (same build number). iPhones (iOS build) and PCs use the same
co-op protocol, so they should be able to play together on the same Wi-Fi.

Saves, settings and the log of the co-op copy:
  %USERPROFILE%\AppData\LocalLow\Cheesecake Dev\Internet Cafe Sim 2 Co-op\
  (InternetCafeSim2-iOS.log is the log; send it if something goes wrong)

Uninstall: delete the "Internet Cafe Simulator 2 Co-op" folder next to the game and the desktop shortcut.
